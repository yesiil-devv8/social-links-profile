# Social Links Profile

A responsive social links profile page built as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge.

## Live Demo

[View Live Site](https://yesiil-devv8.github.io/social-links-profile/)

## GitHub Repository

[View Source Code](https://github.com/yesiil-devv8/social-links-profile)

## About the Project

The goal of this project was to recreate the provided Social Links Profile design using HTML and CSS.

The page displays a profile image, personal information, and a collection of social links in a centered card layout. The design adapts to different screen sizes.

## Built With

- HTML5
- CSS3
- Flexbox
- CSS transitions
- Local font files (Inter)

## Features

- Responsive profile card
- Centered layout using Flexbox
- Circular profile image
- Hover effects for social links
- Visible keyboard focus styles for interactive links
- Reusable CSS custom properties for colors

## What I Learned

While building this project, I practiced:

- Structuring a web page with semantic HTML
- Using CSS Flexbox to center content
- Styling layouts with spacing, colors, and border radius
- Using hover and focus states for interactive elements
- Organizing CSS and reusing values with custom properties
- Checking the layout on different screen sizes

## Getting Started

To run the project locally:

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
